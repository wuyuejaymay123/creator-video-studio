# 短视频创作工作室 · 2.0.2

你给主题、草稿或已经拍好的口播，Skill 根据当前进度继续。核心是一张逐句制作表：一句话为什么说、怎么演、露脸还是仅声音、画面如何按含义变化，以及怎样接到下一句。

拍摄方案默认用日常语言：你说什么、怎么拍、观众看到什么。图片怎么动、两段怎么接也写成能直接想象的过程；专业参数和制图提示词留给 Codex，拍摄时不用读。

## 直接这样用

```text
用 $creator-video-studio 做一条讲“工作流怎么变成 Skill”的视频。
观众是第一次接触的新手。帮我写完整口播稿和拍摄表，开头要有好奇心，
文案口语化。标明露脸或仅声音，给简短表情动作提示。
难懂的地方安排 ImageGen 图和 HyperFrames 动画，
素材与转场跟着台词的含义变化。先交方案。
```

也可以直接给原片：“按这个口播做预览，保留原意，允许去口误和多余停顿；看素材条件安排实拍衔接，不能接的地方给替代剪法。”

## 你会拿到什么

- 单独的纯口播稿，以及台词一致的拍摄表。
- 开头承诺、具体实例和有用的结尾；自然的声音、表情与手势提示。
- 对比、因果、步骤、纠正、类比等关系对应的画面变化。
- 实拍转场的两端拍法、后期衔接、声音处理和替代方案。
- 概念图提示词与分层安排；图片动效和长解释动画交给 HyperFrames。
- 涉及第三方展示时，列出需要你补充的截图或视频，注明对应台词、截什么或录什么、缺少时的做法。
- 进入制作后提供实际预览/成片、可编辑工程与真实检查结果。

策划可以没有素材就开始；图片和视频生产需要环境中可用的相应工具。本包不自带渲染器、图像生成服务或抠像模型，也不保证流量或无须修改的成片。

## 文件与安装

入口在 [SKILL.md](SKILL.md)，按任务读取参考文件。可运行的计划格式见 [说明](references/plan-format.md)，完整示例见 [流程示例](examples/workflow.plan.json)，旧格式示例见 [周报示例](examples/weekly-report.plan.json)。示例没有生成图片或视频，所有拍摄动作均为计划。

将整个 creator-video-studio 目录放在当前客户端的技能发现目录。本机使用 ~/.codex/skills/；更新后重新载入技能或在新会话中调用。原 creator-video-workflow 可以保留，新任务指定本技能即可。

计划助手需要 Python 3.10+，仅使用标准库；运行 python tests/test_plan.py 可检查示例、导出、边界引用与覆盖保护。开发经过与此前版本说明见 [开发记录](PROVENANCE.md)。
